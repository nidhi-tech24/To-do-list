# To-Do List App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Tasks remain saved even after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Project Structure

- `index.html` – Defines the structure of the application.
- `style.css` – Handles the design and styling.
- `script.js` – Manages task operations and Local Storage.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Learning Outcome

This project helped me understand DOM manipulation, JavaScript event handling, and Local Storage.
